# TIGER MasterClass 🐯

Веб-приложение для проведения школьного мастер-класса: команды по 25 человек,
задания от администратора, синхронный тест из 17+ вопросов, выбор кабинета карточками, голосование лайками за ответы
и рейтинг команд в реальном времени. Интерфейс на трёх языках: **КАЗАҚША / РУССКИЙ / ENGLISH**.

## Возможности

- **Авторизация** по логину и общему паролю; роль (админ / лидер / участник) определяется автоматически.
- **8 команд × 25 человек** (1 лидер + 24 участника) = 200 аккаунтов + 10 администраторов.
- **Названия команд**: «1-команда», «2-команда», «3-команда» и так далее.
- **Лидер** — единственный, кто отправляет итоговый ответ команды и прикрепляет фото/видео до 15 МБ.
- **Этапы мастер-класса**: ZERO «Представление команды» → Раунд 1 «Science» → Раунд 2 «Mathematics» (тест) → Раунд 3 «Engineering and Technology» (задание + выбор кабинета) → Раунд 4 «ТИК-ТОК» (кейс-задание, видео).
- **Таймеры заданий** №2 и выше: администратор запускает, ставит на паузу и продлевает время; по окончании приём ответов закрывается.
- **Лайки за ответы** — только для заданий №3 и №4: после окончания времени команды видят ответы друг друга и ставят по одному лайку (за свою команду нельзя). У раундов 1–2 голосования нет.
- **Сектор Голосование (кабинеты)**: 6 переворачивающихся карточек (кабинеты 107, 108, 109, 110, 112, 113). Выбирает только лидер; одна карточка — одной команде, одна команда — одна карточка. Остальные видят, какая команда что выбрала; кабинет видит только выбравшая команда. Администратор может освободить карточку, сбросить выбор и скрыть блок.
- **Редактор в админке**: правка заданий и вопросов теста, фото к заданиям и вопросам.
- **Тест**: вопросы идут **по одному и одновременно у всех** — минута на ответ (время меняется), затем экран с правильным ответом и местом команды в рейтинге, потом следующий вопрос. Отвечает **каждый участник** (один ответ на вопрос), баллы всех правильных ответов суммируются команде в рейтинге.
- **Пульт теста у администратора**: старт, «показать рейтинг сейчас», следующий/предыдущий вопрос, вывод любого вопроса всем, +/− время на ходу, пауза, завершение, изменение времени на вопрос и на показ рейтинга.
- Отдельная страница рейтинга в реальном времени.
- **Рейтинг**: ТОП-10 с раскрытием полного списка; команды без отправок не отображаются.
- **Панель администратора**: перенос участников, смена лидера, ручная правка баллов, просмотр всех ответов, файлов и голосов, публикация заданий, управление тестом, смена логинов/паролей.
- **Mobile-first** адаптивность: крупные кнопки, нижняя навигация на телефоне, боковое меню на ПК.

## Быстрый старт

```bash
# 1. Зависимости (Windows PowerShell)
python -m pip install -r requirements.txt

# 2. Создать базу, команды, 210 аккаунтов и файл с логинами
python scripts/init_db.py

# 3. Запуск
python run.py
```

Ещё проще на Windows: двойной клик по **`start.bat`** — он сам поставит зависимости,
создаст базу при первом запуске и поднимет сервер.

Откройте в браузере: **http://localhost:5000**

Для доступа с телефонов в одной Wi-Fi сети: узнайте IP компьютера (`ipconfig`)
и откройте `http://<IP>:5000` — сервер слушает `0.0.0.0`.

## Пароли

| Роль | Логины | Пароль |
|------|--------|--------|
| Участники и лидеры | `t01-leader`, `t01-p1` … `t08-p24` | `BEKTUROV2026` |
| Администраторы | `admin01` … `admin10` | `TIGERADMIN2026` |

Все 210 аккаунтов выгружены в отдельные текстовые файлы в папке **`credentials/`**:

| Файл | Что внутри |
|------|------------|
| `credentials.txt` | Полный список: 10 админов, затем 8 команд по 25 человек с ролями |
| `credentials.csv` | Та же таблица для Excel / Google Sheets (разделитель `;`) |
| `team_cards.txt` | Карточки команд — распечатать, разрезать и раздать |

Файлы создаются при `python scripts/init_db.py`. Пересоздать их в любой момент
(например, после того как админ поменял логины в панели):

```bash
python scripts/export_credentials.py
```

Логин любого пользователя можно изменить позже в панели администратора
(вкладка «Команды» → «Изменить логин») или через `PATCH /api/admin/users/<id>`.

## Как провести тест (пульт администратора)

Панель администратора → вкладка **«Тест»**:

1. **Открыть тест** — участники видят экран «Тест скоро начнётся».
2. Задать **время на вопрос** (по умолчанию 60 сек) и **время показа рейтинга** (20 сек), нажать «Сохранить».
   Тайминги можно менять и во время теста — новое время применится сразу.
3. **▶️ Начать тест** — первый вопрос появляется у всех одновременно, идёт таймер.
   Лидеры отвечают, ответившие видят «Ответ принят. Ждём остальные команды».
4. Когда время вышло, всем показывается правильный ответ, сколько команд ответило
   и **рейтинг с местом каждой команды**. Через заданное время автоматически включается
   следующий вопрос — снова у всех одновременно.
5. По ходу теста доступны: **🏆 Показать рейтинг сейчас** (не дожидаясь таймера),
   **➡️ Следующий / ⬅️ Предыдущий вопрос**, **+15с / +30с / −15с**, **⏸ Пауза**,
   **🏁 Завершить тест**, а также **«Вывести всем»** у любого вопроса из списка —
   он мгновенно появится у всех участников с новым таймером.
6. Снять галочку **«Автоматически включать следующий вопрос»**, если хотите переключать
   вопросы только вручную (например, чтобы между вопросами обсудить ответ).

## Структура

Подробно: [ARCHITECTURE.md](ARCHITECTURE.md). Правила для агентов и разработчиков: [AGENTS.md](AGENTS.md).

```
backend/    Flask + SQLAlchemy (REST API /api/*)
frontend/   HTML/CSS/JS без сборщика (index.html, app.html, admin.html)
content/    quiz_questions.json (17 вопросов ×3 языка), sections.json (стартовые задания)
scripts/    init_db.py, reset_db.py, rebuild_teams.py, smoke_test.py
data/       SQLite база (не в git)
uploads/    загруженные фото/видео (не в git)
credentials/credentials.txt — логины и пароли (не в git)
```

## Сброс данных перед мероприятием

```bash
python scripts/reset_db.py     # удаляет БД и загруженные файлы, создаёт всё заново
```

## Проверка работоспособности

При запущенном сервере:

```bash
python scripts/smoke_test.py   # 98 проверок: роли, права, файлы, тест, таймеры, голосование, рейтинг
```

Проверку теста удобно запускать на свежей базе (`python scripts/reset_db.py`), иначе
несколько проверок «накопительных» баллов сработают на данных прошлого прогона.

После проверки данные лучше сбросить (`python scripts/reset_db.py`), так как тест
создаёт демонстрационные ответы и баллы.

## Публикация в интернете

Пошаговая инструкция для Timeweb (виртуальный хостинг через файловый менеджер,
Timeweb Cloud App Platform и VPS): **[docs/DEPLOY.md](docs/DEPLOY.md)**.

Кратко: проект — это Python-приложение, поэтому нужен хостинг с поддержкой Python.
Точка входа для production-сервера — `main.py` (`gunicorn main:app`), для Apache/mod_wsgi —
`index.wsgi` вместе с `.htaccess`. При первом открытии сайта база, команды и все
210 аккаунтов создаются автоматически.

## Публикация на GitHub

Git пока не установлен на этой машине. Установка:

```powershell
winget install --id Git.Git -e --source winget
```

Затем (в корне проекта):

```bash
git init
git add .
git commit -m "TIGER MasterClass: initial version"
git branch -M main
git remote add origin https://github.com/<ВАШ_ЛОГИН>/tiger-masterclass.git
git push -u origin main
```

`.gitignore` уже исключает базу, загруженные файлы и `credentials/credentials.txt`,
чтобы пароли и персональные данные не попали в публичный репозиторий.
